## 📌 Propósito y Contexto de esta Organización

Esta organización de GitHub fue constituida y estructurada formalmente por el **Grupo 5** para dar cumplimiento a los requerimientos prácticos y técnicos de la **Evaluación Parcial N° 2: Desarrollo de Pruebas Unitarias y Análisis de Seguridad II** en la asignatura **Ciclo de Vida del Software I (AUY1102)**.

### Caso de Negocio: *Integration Solutions*
La empresa *Integration Solutions* se encuentra en un proceso de transformación digital orientado a superar ciclos de despliegue manuales y lentos mediante la adopción de **GitHub** y prácticas de aseguramiento continuo (**Shift-Left Testing & DevSecOps**).

El Grupo 5 implementó una suite integral de:
1. **Pruebas Unitarias y Cobertura Dinámica:** Instrumentación con Jest e Istanbul para componentes de dominio (*Value Objects*).
2. **Análisis Estático de Seguridad (SAST):** Inspección de código, detección de vulnerabilidades y cumplimiento de *Quality Gate* mediante **SonarCloud**.
3. **Análisis de Composición de Software (SCA):** Auditoría del árbol de dependencias con **Snyk** y **npm audit**.
4. **Gobernanza y Detección de Secretos:** Activación de **GitHub Advanced Security** (*Secret Scanning* y *Dependabot*).
5. **Remediación de Seguridad:** Mitigación de inyecciones SQL, errores de tipado en TypeScript y eliminación de dependencias vulnerables obsoletas.
